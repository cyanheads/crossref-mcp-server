# 0.5.0 — 2026-10-28

## Added

- **`crossref-guide` Agent Skill** — served as the resource `skill://crossref-guide/SKILL.md` (and through the `skill://{+path}` template) via `createApp({ skills: 'skills' })`, and shipped in the npm package (`files` gains `skills/`), the Docker image, and the `.mcpb`. It covers citation-match checks, journal/funder works lists versus filtered search, Crossref filter syntax, DOI prefix versus current publisher, and deposit-dependent coverage.
- **Root `plugin.json` and `mcp.json`** — Agent Plugins 1.0.0 manifests (read by Codex, Cursor, GitHub Copilot, VS Code, Kiro) with a single stdio entry that runs `npx -y @cyanheads/crossref-mcp-server`.

## Changed

- **Tool error text in `content[]` escapes Markdown** (0.13.16, [cyanheads/mcp-ts-core#760](https://github.com/cyanheads/mcp-ts-core/issues/760)) — the `Error:` message, `Recovery:` hint, and `reason` gain backslash escapes; `structuredContent` is unchanged.
- **String trailer values render as inline code** (0.13.18, [cyanheads/mcp-ts-core#785](https://github.com/cyanheads/mcp-ts-core/issues/785)) — values such as `nextWorksCursor` on `crossref_search_journals` and `crossref_search_funders` copy without backslashes; `structuredContent` is unchanged.
- **Anchored `.mcpbignore`** — excludes `/src/`, `/scripts/`, `/tests/`, `/docs/`, `/changelog/`, `/.github/`, the plugin manifests, and other repo-local root paths from the `.mcpb`; root `skills/` ships.
- **Bundle scripts** — `scripts/clean-mcpb.ts` strips the framework's build-only package files (`changelog/`, `scripts/`, `templates/`, `CLAUDE.md`, `AGENTS.md`, config bases) and node-gyp build output from the `.mcpb`; `AGENT_DOC_ENTRY` in it and in `scripts/lint-packaging.ts` matches only package-root agent docs so the MCP SDK's `dist/ext/skills/` modules stay in the bundle ([cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794), covered by `tests/scripts/agent-doc-entry.test.ts`).
- **`lint:packaging`, `check-skills-sync`, `devcheck`** — packaging checks cover the published `skills/` tree, the plugin manifests, and `.mcpbignore` anchoring; `check-skills-sync` reads only `SKILL.md` frontmatter; the Security Audit step classifies a block shared by a direct and a transitive copy by the installed root version.
- **`framework-skills/`** — synced to 0.13.18, with the new `add-skill`.
- **README Getting started** — hosted `claude mcp add --transport http` and local `npx` one-liners, a single client config block, and a Docker section; clone-and-install steps move under Local development.
- **Issue templates, `SECURITY.md`, `CONTRIBUTING.md`** — the bug report's version, runtime, transport, and OS fields become one Environment table; templates ask for shorter descriptions; `SECURITY.md` asks reporters to redact keys and tokens; `CONTRIBUTING.md` drops its pull-request line.
- **`bunfig.toml`** — `minimumReleaseAge` 3 days → 1 day, matching the framework template.
- **`Dockerfile`** — creates `skills/` in the build stage and copies it into the production image.
- **Tests** — error-text assertions in the works, journals, funders, and upstream-classification suites read `content[]` through a CommonMark parse (`renderedText` in `tests/helpers/content.ts`).
