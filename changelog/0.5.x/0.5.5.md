# 0.5.5 — 2026-11-21

## Fixed

- **Text a deposit escaped twice** reads as the text it encodes: a character reference behind a run of `&amp;` decodes as that reference (`&amp;lt;` → `<`, `&amp;amp;rsquo;` → `’`), HTML escaped twice into a JATS field is stripped like HTML escaped once, and an escaped tag's attribute values may be quoted `&quot;…&quot;`. Behind a name the entity table lacks, one level comes off (`&amp;Eng;` → `&Eng;`) (#118).
- **A works page too large for Crossref to assemble** (HTTP 500 naming `ContentTooLongException`) fails on its first attempt as `page_too_large` on `crossref_search_works`, with the size and limit Crossref reports, instead of retrying into `upstream_unavailable`. Its recovery says to halve `rows`, and again if that page is refused too, or to pass `fields` without `author`. The 500's body is read under a 64 KiB bound and a 2 s bound; a 500 whose body does not arrive whole inside them stays `upstream_unavailable` and is retried like every other 500 (#119).
- **`rate_limited` recoveries** advise setting `CROSSREF_MAILTO` only when the server sends no `mailto`, and the server `instructions` no longer carry that advice (#121).
- **A one-character superscript followed by a digit** keeps its braces, so `10<sup>2</sup>5` reads `10^{2}5` instead of `10^25`.

## Dependencies

- `vitest` ^5.1.0 → ^5.1.1 (dev).
