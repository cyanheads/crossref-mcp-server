# 0.5.2 — 2026-11-11

## Added

- **`event`** on `crossref_get_work` and each `crossref_search_works` work — the conference `name`, `location`, `acronym`, `start`, and `end` a proceedings record deposits, with an `**Event:**` line. `event` joins the `fields` enum (20 → 22 names with `approved`) and is selected when `fields` is omitted; a string that normalizes to nothing is dropped (#97).
- **`approved`** on `crossref_get_work` and each `crossref_search_works` work — the date a dissertation or standard deposits in place of a publication date, with an `**Approved:**` line. It is never read into `published`. The `filter` description and the `crossref-guide` skill name `from-approved-date` and `until-approved-date` as its filters (#99).
- **`institutions`, `degree`, `subtype`, and `groupTitle`** on `crossref_get_work` — a thesis's or report's awarding institutions (`name`, `ror`, `place`, `department`, `acronym`) and degree, and a preprint's subtype and group title, each rendered in `content[]`. `subtype` passes through byte-exact like `type`; a string that normalizes to nothing is dropped from `groupTitle`, `degree`, and an institution's place, department, and acronym (#100).
- **`data.citation`** on `doi_not_found` for a DOI registered with DataCite, JaLC, mEDRA, KISTI, or OP — `crossref_get_work` and `crossref_get_references` fetch its CSL-JSON from doi.org within the registry lookup's one `CROSSREF_TIMEOUT_MS` deadline and put `title`, the first 25 `authors`, `authorCount`, `containerTitle`, `issued`, `publisher`, and `type` in both `data.citation` and the message. Any other outcome returns the error without `citation` (#104).
- **`select` and the `query.*` names as `crossref_search_works` input aliases** — `select` for `fields`, and `query.bibliographic`, `query.title`, `query.author`, `query.container-title` for the matching `query*` inputs (#103).

## Changed

- **`crossref_search_works` `rows` caps at 600** when `fields` names neither `abstract` nor `author`, and at 250 otherwise (an omitted or empty `fields` selects both). Under a `fields` selection, the clamp notice names the other cap. The `crossref_search_journals` works list takes `rows` up to 1000, and the 500 cap stays on the title-query journal list (#102).
- **Abstracts keep section headings apart from their text** — a `<jats:title>` ends with `: ` ("Objectives: …"), a leading "Abstract" title is dropped, and an abstract with no text left is omitted (#101).
- **The `crossref_search_journals` `rows` description scopes the clamp notice** to a title query without `include_works`, and says an `issn` lookup returns its one journal.
- **The `*` in the `invalid_cursor` hint and the keys `unknown_filter` suggests** render as code spans in `content[]`, carried as the error's `literals`.
- **Text normalization and date parts move out of `crossref-service.ts`** into `markup-text.ts` and `date-parts.ts`; no behavior change.

## Fixed

- **The `crossref_search_works` notice past the ~10K offset ceiling** says a cursor walk starts at the first record, not after the offset page.
- **The `.mcpb` bundle cleaner keeps the MCP SDK's runtime `skills/` modules** — a bundle built with the older cleaner may not start under Node.
