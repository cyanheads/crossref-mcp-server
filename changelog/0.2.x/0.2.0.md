# 0.2.0 — 2026-07-13

## Added

- **`crossref_get_member`** — resolves a Crossref member ID to its publisher/organization record: primary name, alternate imprint names, owned DOI prefixes, registered DOI counts (current/backfile/total), a per-work-type breakdown, and per-category metadata deposit coverage (references, abstracts, ORCIDs, funders, licenses, and more) as current/backfile fractions; throws `member_not_found` for an unregistered ID ([#20](https://github.com/cyanheads/crossref-mcp-server/issues/20)).
- **`crossref_get_prefix`** — resolves a DOI prefix (e.g. `10.1038`) to its owning Crossref member: publisher name and numeric member ID, chaining directly into `crossref_get_member`; throws `prefix_not_found` for an unregistered prefix ([#20](https://github.com/cyanheads/crossref-mcp-server/issues/20)).
