# 0.1.0 — 2026-05-21

## Added

- Project scaffolded from `@cyanheads/mcp-ts-core`.
- Idea seed (`docs/idea.md`) establishing the crossref-mcp-server concept.
- Tool-surface design (`docs/design.md`): five tools — `crossref_get_work`, `crossref_search_works`, `crossref_get_references`, `crossref_search_journals`, `crossref_search_funders` — wrapping the Crossref REST API (~155M registered works).
- Design covers error contracts, DOI validation, filter key syntax (hyphen-separated), cursor-based deep paging, polite-pool User-Agent (`CROSSREF_MAILTO`), DataCanvas spillover for large result sets, and known API limitations (no incoming citations, abstract/reference coverage variance, `select=` not available on single-record fetch).
- Skills synced to `.claude/skills/`.

## Removed

- Unused echo definitions (resource, app-resource, prompt, app-tool) from scaffold — design is tools-only.
