# 0.1.5 — 2026-05-23

## Added

- **AGENTS.md** created — agent protocol reference mirroring CLAUDE.md for non-Claude Code agents.
- **bunfig.toml** added — Bun runtime configuration.
- **Dockerfile** OCI labels filled (`org.opencontainers.image.*`).

## Changed

- **`CrossrefService`** 404 guard: replaced unsafe `'code' in err` cast with `instanceof McpError` check.
- **`crossref_search_works`** option building: replaced imperative `if` guards with declarative spread (`...input.query !== undefined && { query: input.query }`); removed redundant `filter` cast; `rows` default removed (passed as-is from Zod default).
- **Output schemas** (`WorkSummarySchema`, `AuthorSchema`, `FunderSchema`, `LicenseSchema`, `LinkSchema`, and nested object schemas across all five tools): added `.describe()` on every object-level schema for JSON Schema fidelity.
