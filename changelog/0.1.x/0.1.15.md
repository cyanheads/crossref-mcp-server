# 0.1.15 — 2026-06-15

## Added

- **`instructions`** in `createApp()` (`src/index.ts`) — server-level orientation sent to clients on `initialize`: tool overview, `CROSSREF_MAILTO` polite-pool hint, identifier keys (DOI/ISSN/Funder Registry DOI), the typical search → fetch flow, and the no-incoming-citations / `cursor="*"` deep-paging caveats.

## Changed

- **Plugin display identity** unscoped to `crossref-mcp-server` — `name` and the `mcpServers` key in `.claude-plugin/plugin.json`, plus `interface.displayName` and the server key in `.codex-plugin/mcp.json` (`.codex-plugin/plugin.json`). Agent-facing surfaces now show the bare machine name; install `args` stay `@cyanheads/crossref-mcp-server` (the published npm package).
- **`CrossrefService.request`** reads `this.userAgent` / `this.timeoutMs` directly instead of destructuring `this` — keeps Biome 2.5.0's `noUnusedPrivateClassMembers` from misreading the private fields as unused.
- Dependencies: `@biomejs/biome` ^2.4.16 → ^2.5.0, `vitest` ^4.1.8 → ^4.1.9.
