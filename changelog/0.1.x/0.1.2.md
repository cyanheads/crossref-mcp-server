# 0.1.2 — 2026-05-23

## Added

- **MCPB bundle support** — `manifest.json`, `.mcpbignore`, and `bundle`/`lint:packaging`/`audit:refresh`/`publish-mcp` scripts for one-click Claude Desktop install via `.mcpb` extension format

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.1 → ^0.9.5` — picks up `RequestContextLike` (`Context` is now directly assignable, removing the `ctx as unknown as …` cast), plus all 0.9.2–0.9.5 fixes
- **`zod`** `^4.4.3` added as an explicit dependency (was transitive via mcp-ts-core)
- **`invalid_doi` error code** in `crossref_get_work` and `crossref_get_references` — reclassified `InvalidParams → ValidationError` (input fails regex; this is a validation failure, not a bad JSON-RPC parameter shape)
- **`cursor_offset_conflict` and `offset_too_large` error codes** in `crossref_search_works` — reclassified `InvalidParams → ValidationError` for the same reason
- **Skills synced** — `field-test` 2.4 → 2.5, `maintenance` 2.1 → 2.4, `polish-docs-meta` 1.8 → 2.1, `release-and-publish` 2.2 → 2.4
- **Scripts synced** — `devcheck.ts` updated, `lint-packaging.ts` added
