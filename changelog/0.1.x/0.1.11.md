# 0.1.11 — 2026-05-31

## Removed

- **DataCanvas integration** from `crossref_search_works` — dropped `canvas_id` input field, `canvas` output block, spillover logic, and `getCanvas` import. The `canvas_id` handle was dead output: no `dataframe_query`/`dataframe_describe` tool was ever added to consume it, and Crossref works are bibliographic metadata (search-then-resolve, not aggregate-over-rows). ([#26](https://github.com/cyanheads/crossref-mcp-server/issues/26))
- **`src/services/canvas-accessor.ts`** — service file deleted; `setCanvas` import and call removed from `src/index.ts` setup.
- **`CANVAS_PROVIDER_TYPE` config documentation** — env var references dropped from `README.md` and `docs/design.md`.

## Changed

- **`crossref_search_works` test coverage** — `vi.mock` for `canvas-accessor` removed; expanded coverage across all five tools and service utilities (105 tests pass).
- **`devcheck.config.json`** — added `@cyanheads/mcp-ts-core` to `outdated.allowlist`; framework adoption is deferred to a separate pass.
