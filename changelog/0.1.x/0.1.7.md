# 0.1.7 — 2026-05-24

## Fixed

- **`crossref_search_funders`**: `worksCount` was always `null` — mapped from `f.works` (non-existent field) instead of `f['work-count']`. Fixes [#18](https://github.com/cyanheads/crossref-mcp-server/issues/18).
- **`crossref_search_journals`**: `include_works` ambiguity path threw `new Error(...)` (serialized as `-32603 InternalError`) instead of using the tool's typed error contract. Replaced with `ctx.fail('ambiguous_journal', …)` so the error code is `InvalidParams` and the `data.reason` field is populated. Fixes [#19](https://github.com/cyanheads/crossref-mcp-server/issues/19).
