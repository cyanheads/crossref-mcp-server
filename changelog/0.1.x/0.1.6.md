# 0.1.6 — 2026-05-23

## Fixed

- **`crossref_search_works`**: upstream 400 errors now parsed and surfaced with actionable guidance instead of an opaque internal error.
- **`crossref_get_work`** / **`crossref_get_references`**: DOI regex mismatch now surfaces a human-readable format hint rather than the raw regex pattern.
- **`crossref_search_funders`**: `country` field mapped from `f.location` (correct Crossref field) instead of the non-existent `f.country`.
- **`crossref_search_works`**: env var name (`CROSSREF_MAILTO`) removed from tool-facing description — internal implementation detail not relevant to callers.
- **Config**: startup warning now emitted when `CROSSREF_MAILTO` is absent, pointing operators to the polite-pool benefit.
- **Format**: publication dates zero-padded across all tools (e.g. `2024-01-05` not `2024-1-5`).
- **`crossref_search_journals`**: `include_works` with a multi-match query now returns an actionable error directing the caller to narrow the query to a single journal first.
- **`crossref_search_works`**: `filter` parameter description clarified as an object parameter, not a string.
- **Service**: HTML entities in titles and abstracts decoded across all tools (e.g. `&amp;` → `&`).
