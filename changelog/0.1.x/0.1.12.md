# 0.1.12 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.16` → `^0.9.21` — picks up three framework fixes: per-request log context (HTTP transport now emits logs and traces with fresh request + trace/span IDs instead of the frozen boot context); `fetchWithTimeout` strips query-string secrets (e.g. `?api_key=`) from error messages and logs; `withRetry` fails fast on non-retryable errors and `ctx.fail` auto-populates the `retryable` flag.
- **`release:github` script** added (`scripts/release-github.ts`) — automates GitHub Release creation from the annotated tag.
- **`scripts/devcheck.ts`** updated to current framework conventions.
- **`scripts/check-skill-versions.ts`** and **`scripts/release-github.ts`** added to `scripts/`.
- **Skills synced** — `add-tool`, `add-service`, `api-canvas`, `api-context`, `api-linter`, `api-utils`, `design-mcp-server`, `release-and-publish` updated to framework `^0.9.21`; `api-mirror` and `orchestrations` skills added.
- **Plugin manifest args simplified** — `.claude-plugin/plugin.json` and `.codex-plugin/mcp.json` `args` entries no longer include `"run", "start:stdio"` (simplified to just `["-y", "@cyanheads/crossref-mcp-server"]`).
- **README client-config keys** renamed from `"crossref"` to `"crossref-mcp-server"` for consistency with the full package name.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.16 → ^0.9.21
- `vitest` ^4.1.7 → ^4.1.8
