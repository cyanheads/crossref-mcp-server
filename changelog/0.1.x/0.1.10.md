# 0.1.10 — 2026-05-30

## Added

- **`enrichment` block on `crossref_search_works`** — `totalResults`, `returned`, and `notice` now surface in the typed enrichment channel (both `structuredContent` JSON and `content[]` markdown trailer). `totalResults` and `returned` moved from `output` to `enrichment`; `structuredContent` consumers should read them from `enrichment` instead. (closed [#24](https://github.com/cyanheads/crossref-mcp-server/issues/24))
- **`enrichment` block on `crossref_search_journals`** — `journalCount`, `worksTotal`, and `notice` surface in the enrichment channel. `worksTotal` moved from `output` to `enrichment`.
- **`enrichment` block on `crossref_search_funders`** — `funderCount`, `fundedWorksTotal`, and `notice` surface in the enrichment channel. `fundedWorksTotal` moved from `output` to `enrichment`.
- **Empty-result `notice`** on all three search tools — when no records match, a `notice` string appears in `enrichment` with concrete guidance (try a shorter title, check the ISSN format, verify the funder DOI prefix). Absent on successful result pages.

## Changed

- **`crossref_search_works` `output` schema** — `totalResults` and `returned` removed from `output`; values preserved in `enrichment`. Field order changed: `works` now leads the output object, `nextCursor` follows.
- **`crossref_search_journals` `output` schema** — `worksTotal` removed from `output`; value preserved in `enrichment`.
- **`crossref_search_funders` `output` schema** — `fundedWorksTotal` removed from `output`; value preserved in `enrichment`.
- **`format()` trailers on search tools** — totals and guidance removed from inline header text; both now arrive via the enrichment markdown trailer, avoiding duplication across clients.

## Dependency bumps

- `@cyanheads/mcp-ts-core` ^0.9.13 → ^0.9.16
