# 0.3.11 — 2026-08-25

## Fixed

- **Dockerfile** build stage pinned to `--platform=$BUILDPLATFORM` (was target-platform). On an arm64 build host, the `linux/amd64` leg of the multi-arch build ran the build stage under QEMU, where Bun 1.4.0 aborts inside its JSC heap allocator (SIGABRT, exit 134); `dist/` is pure JS with no native artifacts, so building it natively on the host is safe and the production stage still installs its own runtime deps per target. No runtime or client-visible behavior change — the framework template still ships the target-platform build stage ([cyanheads/mcp-ts-core#370](https://github.com/cyanheads/mcp-ts-core/issues/370)). This release is the first to reach GHCR carrying 0.3.10's content; 0.3.10 itself published to npm, the MCP Registry, and GitHub Releases, but its image build silently failed.

431 tests pass; `bun run devcheck` and `bun run rebuild` clean.
