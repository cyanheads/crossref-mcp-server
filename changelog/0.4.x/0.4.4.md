# 0.4.4 — 2026-10-24

## Changed

- **`crossref_get_work` license and link metadata** ([#88](https://github.com/cyanheads/crossref-mcp-server/issues/88)) — optional `licenses[].start` and `links[].contentVersion` preserve deposited values on both output surfaces; missing values stay absent.
- **Cursor restart advisory** ([#87](https://github.com/cyanheads/crossref-mcp-server/issues/87)) — successful requests with an implausible continuation token carry a notice on all three works lists; cursor acceptance and upstream pass-through are unchanged.

## Fixed

- **Metadata coverage fractions** ([#82](https://github.com/cyanheads/crossref-mcp-server/issues/82)) — member and journal text renders exact deposited 0–1 fractions instead of rounded percentages, matching structured output.
- **Numeric JATS superscripts** ([#86](https://github.com/cyanheads/crossref-mcp-server/issues/86)) — shared work and reference normalization retains caret notation such as `10^{16}` and `GeV^2`; numeric footnote markers follow the same rule.
